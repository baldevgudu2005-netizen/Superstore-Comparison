# Product-Sales-Comparison
IBM Product Sales Comparison using Power BI

## Project Overview
This project focuses on analyzing and comparing product sales performance using Power BI. It helps understand business performance through interactive dashboards and visualizations.

## Objectives
- Analyze total sales and total profit.
- Compare product and category performance.
- Track quantity and order trends.
- Analyze regional sales performance.
- Identify business insights using interactive visualizations.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel / CSV
- Data Visualization
- Data Analysis

## Dashboard Features
- Executive Overview
- Sales Analysis
- Profitability Analysis
- Customer & Order Analysis
- Interactive filters and slicers
- KPI cards and charts

## Dataset
The project uses retail store sales data for analyzing product sales, profit, quantity, and other business metrics.

## Project Files
- Power BI Dashboard (.pbix)
- Dataset (.csv / .xlsx)
- Project Report (.pdf)

## Project Outcome
The dashboard provides a clear overview of sales and profitability, helping users compare business performance and make data-driven decisions.
